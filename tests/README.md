# Testes automatizados

Esta pasta vai receber os testes automatizados do Model (classes
`Figura` e `Desenho`) na **Entrega 4**.

Como o Model não depende de Tkinter (veja `src/paint/modelo/figura.py`),
ele pode ser testado sem precisar abrir uma janela gráfica — por
exemplo, com `unittest` ou `pytest`.
